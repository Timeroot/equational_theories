# Eighteen tops cannot have only small degree-five profiles

The proof is now included in the stronger, purely analytic
[all-small-profile exclusion for sixteen through eighteen tops](1485_order_forty_eight_central_all_small.md).

In particular `(h,a,q)=(18,5,5)` and `(18,6,6)` are excluded.
The earlier proof here used the 200-fixture central lemma; the new
argument needs no finite enumeration. This forwarding note preserves
existing links without duplicating the proof.
