# Order twenty-four is impossible at minimum degree two

The proof has been generalized to
[a full central core excludes order six times a square](1485_six_times_square_full_core.md).
That theorem rules out order `6r²` at minimum translation degree `r`
whenever there are exactly `r²` central vertices.

The central-cardinality hypothesis is proved for every minimum-degree-two
model. Taking `r=2` therefore excludes order 24 at minimum degree two.
This does not exclude the possible minimum-degree-three case of order 24.
These are pen-and-paper results, not new Lean declarations.
