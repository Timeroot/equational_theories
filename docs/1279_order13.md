# Separating the spectra of E704 and E1279 at order thirteen

E704 has a thirteen-element model; E1279 has none. The Lean declarations are
`Spectrum.model_704_13`, `Spectrum.not_order_1279_13`, and
`Spectrum.SmallPairs.spectrum_704_ne_1279`. Thus these two spectrum classes
cannot merge. The same obstruction rules out finite FO-definability from
E704 to E1279, registered as
`Equation1279_not_definableFromFin_Equation704_smallSpectrum`.

## The positive side

On `ZMod 13`, put `x*y = 10x+6y`. Its square is `3x`, and

```
(x*x)*y             = 4x+6y,
y*((x*x)*y)         = 11x+7y,
y*(y*((x*x)*y))     = x.
```

All coefficients are modulo thirteen. The last line is exactly E704.
The existing theorem in `Spectrum/Generated/Modular.lean` verifies this
model by ordinary kernel reduction.

## Reducing the negative side

E1279 says `x = y*(((x*x)*y)*y)`. Writing `D(x)=x*x`, with left and right
translations `L_y` and `R_y`, this is

```
L_y R_y² D = identity.
```

On a finite carrier this forces `D`, every `L_y`, and every `R_y` to be
bijective. Equivalently, the multiplication table is Latin and its diagonal
is a permutation. These facts are proved in `SmallPairs/Basic.lean`.

If a non-idempotent element exists, label one such element zero. Otherwise
all elements are idempotent. Next label the cycles of `L_0` consecutively,
starting with its cycle through zero. This gives the chain bound
`f(0,y) ≤ y+1`, and preserves the implication
`f(0,0)=0 → ∀x, f(x,x)=x`.

The cycle containing zero is distinguished; all other cycles can be sorted
by length. There are 272 possibilities at order thirteen. The formal proof
does not trust a Python list of cycle types: the general chain-enumeration
theorem supplies 4,096 rows, and a registered finite check verifies an explicit
conjugation of each into one of the 272 listed rows. Every conjugation fixes
zero, preserving the diagonal normalization.

There is still symmetry after this step: the cycles not containing zero can
be rotated, and cycles of equal length can be exchanged. We use permutations
that also fix one to normalize `f(1,1)`, then `f(1,0)`. A cycle containing an
already fixed point must stay fixed pointwise. Among the unused cycles of any
given length, a new value only needs to be the first point of the first such
cycle. The generator saves the 1,547 distinct permutations needed for the
45,968 combinations of row and two entries, together with their inverses.
The table uses ASCII digits with constant-time byte access; the first row is
also copied into this compact representation and checked against the original
row functions.
`Permutations.lean` checks the inverses; `Reduction.lean` checks that the selected
permutations fix zero and one, commute with the first row, and give the required representatives.
The second permutation fixes the value chosen in the first step. Thus these
restrictions preserve at least one isomorphic copy of every possible model.

## The finite certificates

Each cycle case has a 4,394-variable encoding with 225,836–225,965 clauses for
E1279, the proved cancellation and diagonal restrictions, its fixed zeroth row,
and the two additional normalized cells. The soundness of the shared encoding
is proved in `SmallPairs/Encoding.lean`; the strengthening is proved in
`OrderThirteen/Encoding.lean`.

The encoding uses auxiliary atoms for `q(x,y)=(x*x)*y`. Its two defining
triangles are `(x*x=a, a*y=b, q(x,y)=b)` and
`(q(x,y)=a, a*y=b, y*b=x)`. Any two equalities in either triangle imply the
third, using cancellation and E1279. The original encoding included two of
these three propagation directions; the optimized encoding explicitly adds
the remaining direction. No additional mathematical assumption is involved.

CaDiCaL refutes all 272 cases. Lean checks the saved LRAT certificates and
combines them with the coverage theorem to exclude every thirteen-element
model. There are no `sorry`s; the finite checks use the repository's
explicitly registered `spectrum_native` policy.

An initial unrestricted three-minute search timed out. Splitting into cycle
cases refuted 237 cases within three seconds each; all remaining 35 were
refuted in a subsequent sixty-second-per-case pass. Separate probes also
refuted the idempotent and scalar-homogeneous subclasses, but those subclass
results are not used as additional assumptions in the final proof.

The modules are in `Spectrum/SmallPairs/OrderThirteen/`. Certificate hashes,
sizes, and regeneration timings are recorded in
`data/spectrum/1279_order13_refutations.json`; the compressed proofs are in
`data/spectrum/1279_thirteen_lrat/`. Ordinary builds replay the certificates
without invoking a solver.

The optimized archive contains **75,646,885 compressed bytes** (about 75.6 MB),
down from 342,685,603 bytes: a **78% reduction**. Its largest file is 6,748,854
bytes, down from about 21 MB. The expanded certificates total **275,150,200
bytes**, down from 1,348,176,485 bytes. The longest case search took 8.761
seconds with four workers on this checkout. Changing the auxiliary subterm or
adding its Latin constraints gave smaller benefits than the two symmetry
reductions, so the optimized proof retains the original auxiliary subterm.

The certificate-module build fell from **551 seconds to 120 seconds** with
dependencies cached, about **4.6 times faster**. The optimized checker still
parses one case at a time, and now shares
the common numeric CNF between all cases. Unchanged modules use Lake's normal
build cache. The inverse and normalization modules build in about 2.3 and
6.6 seconds respectively. This remains a computational proof; the smaller archive does not
claim to replace the finite refutation with a purely structural impossibility
argument.

## Reproduction

```sh
python3 scripts/spectrum_1279_thirteen.py
lake build equational_theories.Spectrum.SmallPairs.OrderThirteen.Exclusion
lake build equational_theories.Definability.SmallSpectrumPairs
python3 scripts/spectrum_generate.py --check
```

The Python command verifies the saved CNF and proof hashes and regenerates
the Lean wrappers. Add `--solve --timeout 180 --jobs 8` to reconstruct the
certificates with CaDiCaL.

The combined `equational_theories.Spectrum` and
`equational_theories.Definability.SmallSpectrumPairs` build passed after optimization (4,075
jobs considered), including the spectrum axiom audit. Certificate hashes and
generated-file checks passed. The source-derived relation query for
`E704 → E1279` reports all ten implication/definability modes refuted.
