# E467 has no model of order twelve

`Spectrum.not_order_467_12` is proved in Lean in
[`OrderTwelve/Exclusion.lean`](../equational_theories/Spectrum/Equation467/OrderTwelve/Exclusion.lean).
There are twenty certificates, totaling **429,380 bytes (419 KiB)**; the largest
is 64,020 bytes. A normal parallel `lake build`, with mathematical dependencies
already built, checked the certificates and final assembly in **16.84 seconds**,
with a peak process memory of 2.2 GiB. Individual certificate modules took
roughly four to six seconds, including elaboration. The previous unrestricted
certificate occupied 6.2 MiB and had not finished replay after ten minutes.

## The mathematical reduction

Write E467 as `x = y * (x * (x * (y*y)))`, and let `D(x)=x*x`.
The existing algebra in
[`Equation467Translations.lean`](../equational_theories/Spectrum/Equation467Translations.lean)
proves that all left and right translations are bijections and that `D` is a
permutation. Its inverse is `x ↦ x*(x*x)`. The unique fixed point of both `L_x`
and `L_x²` is `D²(x)`, so no left translation has a nontrivial two-cycle.
Squaring itself has neither two-cycles nor three-cycles.

Mathlib's permutation-conjugacy theorem reduces `D` to one of the 77 canonical
cycle types on twelve labels. The two preceding exclusions remove 57 types,
leaving twenty. Once `D` is fixed, the original law becomes

```
D⁻¹(y) * (x * (x*y)) = x.
```

This uses only multiplication-table variables. Left cancellation gives all
three propagation directions between the table entries in this identity.
The encoding also includes the proved diagonal, inverse, fixed-point, and
no-two-cycle conditions. No separate auxiliary operation table is needed.

The identity-diagonal case allows the usual first-row normalization. In each
other case, the moved labels of `D` form an initial block of size `k` and
`D(0)=1`. The first two row entries are `0*0=1` and `0*1=D⁻¹(0)`, both inside
that block. Traversing the rest of row zero and swapping unused labels gives
`0*y ≤ y+(k-2)` while fixing the initial block pointwise. All other labels are
fixed points of `D`, so these swaps preserve the whole squaring permutation.
This generic argument is proved in
[`OrderTwelve/Normalization.lean`](../equational_theories/Spectrum/Equation467/OrderTwelve/Normalization.lean).

## Verification and reproduction

The encoding soundness, permutation coverage, normalization, and assembly
are Lean proofs without `sorry`. CaDiCaL provides data only: registered native
checks reconstruct the compact RUP refutations and use Lean's verified LRAT
checker. All twenty Lean-exported CNFs match the independently generated
Python inputs byte for byte. Each proof-producing search took under 0.3 seconds.

```sh
python3 scripts/spectrum_467_twelve.py
lake build equational_theories.Spectrum.Equation467.OrderTwelve.Exclusion
lake env lean --run equational_theories/Spectrum/Equation467/OrderTwelve/Export.lean /tmp/e467-twelve-cnf
python3 scripts/spectrum_467_twelve.py --check-lean-cnf /tmp/e467-twelve-cnf
```

The script's `--solve` option recreates the certificates with bounded solver
runs. Ordinary builds never invoke the solver. Hashes, sizes and individual
search timings are in [`467_order12.json`](../data/spectrum/467_order12.json).
