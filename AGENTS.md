# Repository instructions

## Git identity

Every commit in this repository must use:

```sh
git commit --author="Alex Meiburg <timeroot.alex@gmail.com>"
```

Add other commit options as needed, including when amending commits.
Both the author and committer must be `Alex Meiburg <timeroot.alex@gmail.com>`.
Keep `user.name` and `user.email` set accordingly in this repository's local Git
configuration; do not change the global identity for other repositories.
